LUZ CIVIC TERMINAL 0.7.6
Mod management, protected saves and author packaging for Nivalis Nights

CHOOSE ONE DOWNLOAD

Windows PC: win-x64.zip.
Linux x64 desktop: linux-x64.zip.
Intel Mac: osx-x64.zip.
Apple Silicon Mac: osx-arm64.zip.

Windows is the main desktop build. Linux and macOS builds are experimental.
Protected game sessions require native Windows. .NET is included.
Extract the whole ZIP outside the game. Keep its files together.

INSTALL LUZ

Windows
1. Right-click the ZIP and choose Extract All.
2. Open the extracted folder and run Install LUZ.exe.
3. Click Install and create shortcut, then open the desktop shortcut.

Linux
1. Extract the ZIP to a writable folder.
2. Run ./"Install LUZ" from that folder.
   If needed: chmod +x "Install LUZ" "LUZ Civic Terminal"
3. Click Install and create shortcut. Your desktop may require Allow Launching.
   A graphical glibc desktop with X11/XWayland and xdg-open is required.

macOS 15 or newer
1. Extract the ZIP for your processor.
2. Run Prepare macOS.command to apply a local signature.
   If needed, open Terminal there and run: sh "Prepare macOS.command"
3. Run Install LUZ.command and click Install and create shortcut.
4. Open the shortcut. The application is not notarized. For a trusted copy,
   macOS Privacy & Security > Open Anyway may be required.

For portable use, open LUZ Civic Terminal directly instead of the installer.

PLAYERS: SET UP YOUR MODS

1. Close Nivalis. In Civic Terminal > Maintenance, check Game location.
   Use Detect Steam install or Choose game folder if it is wrong.
2. Already have mods? Select your intended profile and choose Import existing
   installation before the first Apply. This copies its mods and settings.
3. If needed, choose Install recommended BepInEx. LUZ downloads the official
   Windows x64 IL2CPP build 6.0.0-be.788 and backs up replaced loader files.
   After first-time installation, launch the game yourself once, let loader
   initialization finish, then close it.
4. In Registry, choose Import ZIP / DLL. Select a mod's complete ZIP and add
   its required dependencies. Catalogue also offers package downloads.
5. Enable the desired mods. Review Profile issues and use Auto-sort if needed.
6. With the game closed, choose Apply profile and review the proposed change.
   Expected: the profile is shown as applied to the game.
7. Choose Play Nivalis when ready.

Import adds files to LUZ. Apply installs the selected profile. Play starts the
game. Apply replaces deployed plugins and patchers with that profile's contents.
Ordinary profiles can use your usual launcher; protected saves must use Play
through LUZ.

MOD AUTHORS: BUILD YOUR FIRST PACKAGE

1. Open CorpSec Terminal > Add mods folder. Select the folder where your build
   writes DLLs or release ZIPs. Choose your mod from My mods.
2. In Project, verify Current build and Build edition to follow, if shown.
   Fill in Author, Description, Website and Support contact. Switching to
   another section saves those fields.
3. In LUZ Support, click Analyze this build. Review the detected information.
4. Answer Where does this mod keep persistent state?
   No extra persistent state: no mod-owned data needs restoration.
   Separate save or configuration files: declare the files you own.
   State stored inside the game save / Custom recovery adapter: reuse a
   supported integration or supply the required recovery implementation.
   I don't know yet: keep recovery incomplete and use a normal export.
5. Resolve the listed actions. For recovery support, click Generate support
   files. Expected: Package checks passed and Recovery declaration checks
   passed. In-game recovery has not been tested remains a separate result.
6. Open Package. Choose Normal package or Package with LUZ recovery support.
7. Choose output folder once, then review Package file list.
8. Click Build Nexus ZIP. Expected: a Built message naming the ZIP, with its
   checksum beside it in your output folder.
9. For Thunderstore, review the package name and supply any required plugin
   dependency mappings, then click Build Thunderstore ZIP or Build both.

For your next release, compile the mod into the watched folder and build its
package again. CorpSec refreshes the selected edition and regenerates support.
No need to reopen each release ZIP or arrange the LUZ folder manually.

CORPSEC-GUIDE.md explains every step, the saved-data choices, dependency
mappings, build integration, custom recovery and troubleshooting.

OPTIONAL PROTECTED SAVES

Read Continuity/README.md first. In Maintenance > Mod Continuity, Enable
protected saves selects an original native save. Apply compatible mods, then
use Play in LUZ to prepare a checkpoint and a separate protected timeline.

Protection requires native Windows, supported game build 25984046, loader
6.0.0-be.788 and compatible mod support. Author declarations do not qualify
unknown game behavior. Keep separate backups for saves outside protection.

UPDATES AND HELP

Maintenance > LUZ updates checks GitHub. Startup checks and automatic
installation have separate preferences. LUZ 0.4.0+ can use the updater;
0.3.x users need one manual installation. Profiles and author settings remain
in LUZ's separate data folder. Do not mix files from different releases.

After a game update, use Diagnose game update. Refresh game bindings backs up
generated bindings and enables regeneration on your next launch. An unsupported
mod still needs a compatible release.

For a failed Apply or loader installation, use the matching Recovery required
action in Maintenance. Export diagnostics captures a report for support.
