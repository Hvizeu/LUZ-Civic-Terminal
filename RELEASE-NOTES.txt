# LUZ Civic Terminal 0.8.2

LUZ can now be installed from its Nivalis Nights Nexus page with Mod Manager Download. Once canonical Nivalis Nights Support is active, Vortex recognizes the official Windows package, installs it as an isolated tool, connects it to the correct Steam installation, and makes LUZ the primary tool automatically.

The extension still finds an existing installation or asks Vortex to obtain the current Windows Main File from Nexus when LUZ is missing. Vortex uses its signed-in Nexus account; no LUZ API key is required. Both routes use the same idempotent pairing process.

Routine use is install or update a mod in Vortex, then press Play. Vortex exports the completed installer-selected packages; LUZ synchronizes the selected profile, applies it through the existing safeguards when safe, and stays open at its launcher. Vortex Play never launches Nivalis.

New supported packages enter the selected LUZ profile enabled. Existing order, disabled state, pins, and notes remain intact. Removing a package from Vortex leaves its imported LUZ copy in place and marks the update source unavailable.

Users migrating from the earlier direct-deployment extension may need to use Purge Mods once before managing the game again. No existing deployment is removed silently.

Windows is the main desktop build. Linux and macOS builds are experimental. Protected game sessions require native Windows, catalogued game build 26118043 or retained recovery identity 25984046, BepInEx 6.0.0-be.788 and compatible mods.
