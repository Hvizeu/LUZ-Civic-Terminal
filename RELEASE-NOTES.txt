# LUZ Civic Terminal 0.7.6

Changes since 0.7.2:

- Fixed Nexus and local imports checking Nivalis Expanded's Unofficial Patch requirement by plugin version.
- Fixed Apply after importing installed mods that are disabled.
- Repaired orphaned package folders during import while preserving disabled and pinned settings.
- Added saved-data recovery support for Culinary Inspiration and restaurant reviews.

## Installation

Download the ZIP for your platform and extract the whole archive outside the game folder. Run its installer. .NET is included. Existing users on LUZ 0.4.0 or newer can use Maintenance > LUZ updates; 0.3.x requires a manual installation. Profiles and author settings remain in LUZ's separate data folder.

Windows is the main desktop build. Linux and macOS builds are experimental; macOS packages are not notarized. Protected game sessions require native Windows, Nivalis Nights build 25984046, BepInEx 6.0.0-be.788 and compatible mods. Ordinary mod management works without protected saves.
