# LUZ Civic Terminal 0.8.7

BepInEx installation and updates now always resolve the latest completed official Windows x64 IL2CPP build. The older pinned recommended-build option has been removed; failed discovery never installs an older fallback.

Vortex results refresh immediately after synchronization. Excluding a reviewed package now has a short visible button and automatically retries the synchronization, while retaining its Vortex files and the installed loader.

The companion extension remains 0.6.2. Existing users only need to update LUZ for these changes.
