# LUZ Civic Terminal 0.8.6

Vortex synchronization now reads verified snapshots without recursively rejecting Vortex-owned linked deployment files beside them. Snapshot manifests, payloads, control paths and game deployment retain their link checks.

Existing Vortex connections can refresh after mods have been deployed. Profiles, disabled states, pins and loader-review decisions are preserved. Vortex Play continues to open LUZ without launching Nivalis.

Includes LUZ for Nivalis Nights extension 0.6.2, with corrected startup registration, discovery and primary-tool handoff.

If extension 0.6.2 is already installed, update LUZ only. Users on older extension versions should also install the included 0.6.2 extension ZIP through Vortex Home > Extensions and restart Vortex when prompted.
