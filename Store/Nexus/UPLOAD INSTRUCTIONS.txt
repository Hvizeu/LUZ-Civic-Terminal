FILES

Upload the four platform ZIPs from the LUZ deployment folder as separate files.
Do not re-ZIP them or upload the private QA/status records.

Main Windows file
  Filename: LUZ-Civic-Terminal-0.7.7-win-x64.zip
  Display name: LUZ Civic Terminal 0.7.7 - Windows x64
  Description: Mod management and CorpSec author tools. Includes the installer,
  .NET, bundled Mod Continuity and step-by-step guides. Extract outside the
  game and run Install LUZ.exe.

  Filename: LUZ-Civic-Terminal-0.7.7-linux-x64.zip
  Display name: LUZ Civic Terminal 0.7.7 - Linux x64 (experimental)

  Includes installation and author guides. Protected game sessions require
  native Windows.

Optional Intel Mac file
  Filename: LUZ-Civic-Terminal-0.7.7-osx-x64.zip
  Display name: LUZ Civic Terminal 0.7.7 - macOS Intel (experimental)

Optional Apple Silicon file
  Filename: LUZ-Civic-Terminal-0.7.7-osx-arm64.zip
  Display name: LUZ Civic Terminal 0.7.7 - macOS Apple Silicon (experimental)

Every ZIP has a .sha256 sidecar. Use it to verify the selected upload matches
the release package. Players need only the ZIP for their platform.

PAGE UPDATE

1. Set the version to 0.7.7.
2. Paste DESCRIPTION.bbcode.txt into the existing page's BBCode description.
   Keep the endorsement image and the clickable Ko-fi banner directly below it.
   Keep any existing gallery images and required credits.
3. Paste CHANGELOG.txt into the new version's changelog.
4. Use SUMMARY.txt for the short description.
5. Confirm Windows is the main download and the other platforms are clearly
   labelled experimental.
6. Check the rendered page: cyan player features, gold author tools, green
   save features and purple maintenance features should have large headings.
7. Check that the page's current requirements distinguish ordinary mod
   management from protected saves, which require native Windows, supported
   game build 26118043 or retained recovery identity 25984046, loader
   6.0.0-be.788 and compatible mod support.

UPGRADE NOTES

LUZ 0.4.0+ can use Maintenance > LUZ updates. Users on 0.3.x need one manual
installation. Keep profiles and author settings; do not mix application
files from different versions.

The GitHub updater release uses these same four ZIP filenames and checksums.
No Nexus page edits or uploads are performed by preparing these files.
