[size=6][b]LUZ Civic Terminal[/b][/size]

LUZ puts Nivalis mod installation, profiles and BepInEx setup in one application. Civic Terminal manages the mods you play with; CorpSec Terminal prepares your own mods for release.

[size=4][b]Install mods and manage profiles[/b][/size]

Import Nexus ZIPs, individual DLLs or the mods already installed in your game. Create profiles, choose enabled mods, sort them and Apply the selected setup. Dependency and file-conflict checks run before deployment. Import an existing installation before the first Apply to keep those mods.

Manual Nexus ZIP imports need no API key. Nexus lookup and permitted direct downloads use your own key and follow your account's permissions. Install required mods separately.

[size=4][b]BepInEx and maintenance[/b][/size]

Install the recommended BepInEx 6 IL2CPP build 788, back up replaced loader files and restore a backup when needed. Maintenance also provides profile backups, interrupted-deployment recovery, game-update diagnosis and a diagnostics export.

LUZ can check its GitHub releases for application updates. Updates preserve profiles and CorpSec projects.

[size=4][b]CorpSec Terminal for authors[/b][/size]

Add a build folder once, select the plugin and save author details, edition and output choices. Analyze this build inspects assemblies, packaged assets and optional source without running the mod.

Review detected saved data and declare the files your mod owns. Generate support files adds package-local LUZ information without rewriting the plugin. Authors provide any recovery behaviour that cannot be inferred.

Build a Nexus ZIP with its checksum, inspect the file list and reuse the saved project for the next release. Normal standalone exports remain available when recovery support is incomplete. Command-line and build-integration tools support automated packaging.

[size=4][b]Protected saves[/b][/size]

Optional Mod Continuity creates an original checkpoint and a separate protected timeline. Supported mods can preserve data while features are unavailable, then restore them when a compatible implementation returns. Interrupted saves retain recovery information.

Protected sessions require native Windows, Nivalis Nights Steam build 25984046, BepInEx build 788 and compatible mod support. Wine/Proton protection is unsupported. Ordinary profiles can be used without protection. A save that depends on a missing object or serialization provider still needs that provider.

[size=4][b]Installation[/b][/size]

Download one platform ZIP and extract it outside the game folder. On Windows, run Install LUZ.exe and choose Install and create shortcut, or run the extracted application directly for portable use. .NET is included.

Linux x64 and macOS Intel/Apple Silicon downloads are experimental. Linux needs a graphical glibc desktop with X11/XWayland; macOS needs version 15 or newer. Follow the included platform helpers. Mac packages are not notarized. Nivalis itself still requires an existing Proton or Wine/CrossOver setup on those systems.

The player and CorpSec guides are included. Use Maintenance > Export diagnostics for a report, alongside your OS, LUZ version, exact steps and full error.

[size=4][b]Nexus links[/b][/size]

Making LUZ the NXM handler affects Nexus links across all games. Keep your existing manager if you need it for other games and use manual import or Paste download link instead. LUZ supports Nivalis BepInEx ZIPs and DLLs; it does not install Nexus Collections, FOMODs or RAR/7z archives.
